# 📦 Stock Management System Frontend

A modern, professional, and responsive Stock Management System frontend built with React.js, Tailwind CSS, React Router, Recharts, and Context API. This is a fully functional frontend demo with dummy data, dark/light mode, and full CRUD operations – no backend or API required.

## ✨ Features

- **Complete Dashboard** – Statistics cards, interactive charts (stock movement, inventory value, category distribution, purchase summary), recent activities.
- **Product Management** – List, search, filter, sort, pagination, add/edit/delete products, product details page.
- **Category Management** – CRUD operations on product categories.
- **Inventory Tracking** – View stock levels with status badges (In Stock, Low Stock, Critical, Out of Stock). Export to CSV.
- **Stock In / Stock Out** – Record incoming and outgoing stock, automatically update product quantities.
- **Supplier Management** – Manage supplier information, view supplied products and purchase history.
- **Purchase Orders** – Create, edit, and track purchase orders with line items.
- **Reports** – Inventory, Stock In/Out, Supplier, and Purchase reports with date filters and CSV export.
- **Notifications** – Alerts for low stock, out of stock, new suppliers, purchase order updates. Mark as read / delete.
- **User Management** – Manage system users with roles (Admin, Manager, Staff).
- **Settings** – Company settings, inventory defaults, user preferences (theme, language, notifications).
- **Dark / Light Mode** – Toggle theme, persists in localStorage.
- **Responsive Design** – Mobile-friendly sidebar drawer, collapsible sidebar on desktop.
- **Reusable UI Components** – Buttons, modals, tables, cards, badges, pagination, etc.

## 🛠️ Tech Stack

- **React 18** – Functional components + hooks
- **React Router DOM v6** – Client-side routing
- **Tailwind CSS** – Utility-first styling, dark mode support
- **React Icons** – Icon library
- **Recharts** – Charts and graphs
- **Context API** – State management (no Redux)
- **LocalStorage** – Persists data across page reloads
